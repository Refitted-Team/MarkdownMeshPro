# Markdown Mesh Pro
Markdown Mesh Pro is a simple MarkDown renderer for unity TextMeshPro with the help of [MarkDig](https://github.com/xoofx/markdig).

# Features
supports:
- headings
- lists
- inline quotes
- tables
- emphasis
- auto links
- code blocks
- quote blocks

and more coming soon
